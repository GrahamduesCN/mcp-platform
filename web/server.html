About

Secure file system access for AI agents. Read, write, and manage files across your workspace with full permission control. Supports all major operating systems.

Features

  • Read and write files with configurable access scopes
  • Directory listing and traversal
  • File metadata retrieval (size, timestamps, permissions)
  • Cross-platform support (Windows, macOS, Linux)
  • Sandboxed access with allow/deny path patterns

Quick Start

1. Install the server:

npx mcp install mcp-filesystem

2. Configure allowed paths:

{ "allowPaths": ["/home/user/projects"] }
